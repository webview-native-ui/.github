# Security Policy

Please report suspected security vulnerabilities privately rather than through public issues or discussions.

If the affected repository enables GitHub private vulnerability reporting, use its **Security → Report a vulnerability** option. Otherwise contact a maintainer using a private contact method explicitly published by that repository.

Include the affected package and version, platform, reproduction steps, impact and any known mitigations. Do not share live credentials or sensitive personal data.

Maintainers will assess and coordinate remediation and disclosure in accordance with the affected project's release process. No specific response or remediation timeline is guaranteed.
